# 今日头条平台规范

## 输出格式
- 主格式：富文本 HTML
- 备用格式：Word 文档 (.docx)

## 内容参数
- 字数：1000-2000 字
- 标题：通俗易懂、接地气、标题吸引点击
- 风格：大众化、有信息量
- 结构：吸引人的开头 → 详实内容 → 结尾留悬念或引导评论

## 配图要求
- 封面模式：三图模式（1:1 或 16:9）
- 内文配图：2-4 张
- 图片格式：JPG/PNG，清晰度高

## SEO / 推荐优化
- 标题是推荐权重的核心
- 包含热门关键词
- 开头 50 字决定是否被推荐
- 引导评论和转发

## 排版特性
- 标准 HTML
- 段落不宜过长，善用分段
- 图片穿插在段落之间
- 支持加粗关键信息

## 文件命名
- `toutiao_{slug}.html`
- `toutiao_{slug}.docx`
- `images/toutiao_cover_{n}.png`（三图封面）
- `images/toutiao_{n}.png`

## 手动发布指引
1. 登录今日头条创作者后台
2. 发布图文
3. 选择三图封面模式
4. 复制 HTML 内容到编辑器（或导入 Word）
5. 上传封面三图
6. 设置分类标签后发布
