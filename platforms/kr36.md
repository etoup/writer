# 36氪平台规范

## 输出格式
- 主格式：Markdown
- 备用格式：Word 文档 (.docx)

## 内容参数
- 字数：1500-3000 字
- 标题：商业分析风格，专业且有吸引力
- 风格：数据驱动、创投视角、商业洞察
- 结构：行业背景 → 核心分析 → 数据/案例支撑 → 总结展望

## 配图要求
- 比例：16:9
- 数量：1-2 张
- 类型：数据图表、行业分析图、信息图
- 图片风格：专业、简洁、数据可视化

## SEO / 标签
- 适合创投领域搜索
- 标题包含行业关键词
- 支持投稿流程

## 排版特性
- 支持代码块
- 支持数据表格
- 支持引用
- 支持 Markdown 全部特性

## 文件命名
- `kr36_{slug}.md`
- `kr36_{slug}.docx`
- `images/kr36_{n}.png`

## 手动发布指引
1. 36氪主要通过投稿/作者入驻流程
2. 准备 Markdown 或 Word 文档
3. 通过官方渠道提交稿件
4. 等待编辑审核
