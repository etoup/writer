# 大鱼号平台规范

## 输出格式
- 主格式：富文本 HTML
- 备用格式：Word 文档 (.docx)

## 内容参数
- 字数：1000-2000 字
- 标题：综合资讯风格，平衡吸引力和信息量
- 风格：大众化、信息密度适中
- 结构：导语 → 正文 → 结语

## 配图要求
- 封面比例：16:9
- 内文配图：2-3 张
- 图片格式：JPG/PNG

## SEO / 推荐优化
- 适合 UC 浏览器推荐流
- 标题包含热门关键词
- 正文前 100 字决定推荐权重

## 排版特性
- 标准 HTML
- 段落清晰
- 图片居中
- 支持加粗和引用

## 文件命名
- `dayu_{slug}.html`
- `dayu_{slug}.docx`
- `images/dayu_cover_{slug}.png`
- `images/dayu_{n}.png`

## 手动发布指引
1. 登录大鱼号后台
2. 新建图文
3. 复制 HTML 内容到编辑器（或导入 Word）
4. 上传封面图
5. 设置分类后发布
