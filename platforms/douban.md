# 豆瓣平台规范

## 输出格式
- 主格式：Markdown
- 备用格式：Word 文档 (.docx)

## 内容参数
- 字数：800-2500 字
- 标题：个人化、有态度、偏文艺
- 风格：个人视角、真诚表达
- 结构：自由灵活，重个人感受和思考

## 配图要求
- 比例：16:9
- 数量：可选，0-3 张
- 图片风格：生活化、有温度

## SEO / 标签
- 豆瓣以社区推荐为主
- 发布到对应小组增加曝光
- 标题和内容自然融入关键词

## 排版特性
- 标准 Markdown
- 支持图片
- 支持引用、列表
- 段落不宜过长，保持可读性

## 文件命名
- `douban_{slug}.md`
- `douban_{slug}.docx`
- `images/douban_{n}.png`

## 手动发布指引
1. 登录豆瓣
2. 写日记 或 发广播（长文）
3. 复制 Markdown 内容
4. 手动插入图片（豆瓣不支持 Markdown 图片语法）
5. 发布
