# 抖音平台规范

## 输出格式
- 主格式：短视频脚本（分镜脚本 + 口播文案）
- 备用格式：图文模式（配合轮播图）

## 内容参数（短视频）
- 时长：15-60 秒（主流）或 1-3 分钟（深度内容）
- 字数：按语速 250 字/分钟计算（15 秒约 60 字）
- 风格：节奏快、开头 3 秒抓人、情绪饱满
- 结构：前 3 秒钩子 → 核心内容（10-30 秒）→ 互动引导

## 封面/首帧要求
- 比例：9:16（1080x1920）
- 风格：视觉冲击力强、标题文字醒目
- 人物出镜优先，表情生动

## 图文模式
- 图片数量：3-9 张
- 比例：3:4 或 9:16
- 每张配 1-2 句文案
- 适合：教程、清单、测评、故事

## SEO / 话题
- 标题：简短有力，包含核心关键词
- 话题标签：3-5 个 #话题#
- 音乐选择：使用热门 BGM 增加推荐权重

## 文件命名
- `douyin_script_{slug}.md`（视频脚本）
- `douyin_article_{slug}.md`（图文模式文案）
- `douyin_{slug}.docx`
- `images/douyin_cover_{slug}.png`（9:16 封面）

## 手动发布指引
1. 打开抖音 App
2. 点击 + 号 → 拍摄/上传
3. 视频：拍摄或上传视频，添加文字/滤镜/音乐
4. 图文：选择多张图片，自动切换播放
5. 填写标题和话题标签 → 发布
