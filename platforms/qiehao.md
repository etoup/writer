# 企鹅号平台规范

## 输出格式
- 主格式：富文本 HTML
- 备用格式：Word 文档 (.docx)

## 内容参数
- 字数：1000-2000 字
- 标题：综合媒体风格，平衡专业性和可读性
- 风格：资讯类、信息密度高
- 结构：导语 → 正文分段 → 总结

## 配图要求
- 封面比例：16:9
- 内文配图：2-3 张
- 图片格式：JPG/PNG

## SEO / 推荐优化
- 适合腾讯新闻推荐流
- 标题包含关键词
- 正文前 100 字决定推荐权重

## 排版特性
- 标准 HTML
- 段落简洁
- 图片居中对齐
- 支持引用和列表

## 文件命名
- `qiehao_{slug}.html`
- `qiehao_{slug}.docx`
- `images/qiehao_cover_{slug}.png`
- `images/qiehao_{n}.png`

## 手动发布指引
1. 登录企鹅号后台
2. 新建图文
3. 复制 HTML 内容到编辑器（或导入 Word）
4. 上传封面图
5. 设置分类后发布
