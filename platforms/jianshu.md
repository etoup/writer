# 简书平台规范

## 输出格式
- 主格式：Markdown（简书原生支持）
- 备用格式：Word 文档 (.docx)

## 内容参数
- 字数：1000-3000 字
- 标题：文艺/深度，有文学感
- 风格：个人化、有态度、偏文艺或深度
- 结构：自由，可以是叙事、分析、随笔

## 配图要求
- 比例：16:9
- 数量：可选，0-3 张
- 图片风格：有质感、有氛围

## SEO / 标签
- 设置 2-4 个标签
- 投稿到相关专题增加曝光
- 标题包含核心关键词

## 排版特性
- 简书原生支持 Markdown
- 支持代码块
- 支持引用、表格、列表
- 支持图片插入
- 支持分隔线（---）

## 文件命名
- `jianshu_{slug}.md`
- `jianshu_{slug}.docx`
- `images/jianshu_{n}.png`

## 手动发布指引
1. 登录简书
2. 写文章
3. 直接粘贴 Markdown 内容
4. 上传图片（拖拽或点击插入）
5. 设置标签、投稿专题后发布
