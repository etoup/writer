# 搜狐号平台规范

## 输出格式
- 主格式：富文本 HTML
- 备用格式：Word 文档 (.docx)

## 内容参数
- 字数：1000-2500 字
- 标题：新闻资讯风格，客观中立
- 风格：新闻报道式、信息量大
- 结构：导语 → 正文 → 结语

## 配图要求
- 封面比例：16:9
- 内文配图：2-3 张
- 图片格式：JPG/PNG

## SEO / 推荐优化
- 标题包含关键词
- 适合搜狐搜索和百度收录
- 标签：3-5 个分类标签

## 排版特性
- 标准 HTML
- 支持段落间距
- 支持图片居中
- 支持引用块

## 文件命名
- `sohu_{slug}.html`
- `sohu_{slug}.docx`
- `images/sohu_cover_{slug}.png`
- `images/sohu_{n}.png`

## 手动发布指引
1. 登录搜狐号后台
2. 新建文章
3. 复制 HTML 内容到编辑器（或导入 Word）
4. 上传封面图
5. 设置分类标签后发布
