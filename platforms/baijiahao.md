# 百家号平台规范

## 输出格式
- 主格式：富文本 HTML
- 备用格式：Word 文档 (.docx)

## 内容参数
- 字数：1000-2000 字
- 标题：通俗易懂，适度标题党
- 风格：大众化、易读
- 结构：开头吸引 → 正文展开 → 结尾引导互动

## 配图要求
- 封面比例：16:9
- 内文配图：2-3 张
- 图片格式：JPG/PNG

## SEO / 推荐优化
- 标题包含热门关键词
- 正文关键词密度 2-3%
- 适合百度搜索收录

## 排版特性
- 标准 HTML，无需微信特化修复
- 支持图片居中
- 支持段落间距调整
- 支持加粗、引用、列表

## 文件命名
- `baijiahao_{slug}.html`
- `baijiahao_{slug}.docx`
- `images/bjh_cover_{slug}.png`
- `images/bjh_{n}.png`

## 手动发布指引
1. 登录百家号后台
2. 新建图文
3. 复制 HTML 内容到编辑器（或导入 Word）
4. 上传封面图
5. 检查图片显示正常后发布
