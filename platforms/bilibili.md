# 哔哩哔哩（B站）平台规范

## 输出格式
- 主格式：视频脚本（分镜脚本）
- 备用格式：专栏 Markdown + Word

## 内容参数（视频脚本）
- 时长：3-8 分钟（中长视频）或 30-60 秒（短视频）
- 字数：按语速 200-250 字/分钟计算
- 风格：专业但不枯燥，适当玩梗，有互动引导
- 结构：开头钩子（5 秒）→ 内容展开 → 互动引导（点赞/收藏/关注）

## 封面要求
- 比例：16:9（1920x1080）
- 风格：信息量大、有冲击力、标题文字突出
- 建议包含：人物/表情/关键词/数字

## 专栏文章
- 字数：1000-3000 字
- 支持代码块、图片、视频嵌入
- 适合知识分享类内容

## SEO / 标签
- 标题包含核心搜索词
- 标签：3-8 个，涵盖大类和小类
- 分区选择准确（科技/知识/生活/游戏等）

## 文件命名
- `bilibili_script_{slug}.md`（视频脚本）
- `bilibili_article_{slug}.md`（专栏文章）
- `bilibili_{slug}.docx`
- `images/bilibili_cover_{slug}.png`

## 手动发布指引
1. 登录 B 站创作者中心
2. 投稿 → 选择视频/专栏
3. 视频：上传视频文件，填写标题、简介、标签、封面
4. 专栏：粘贴 Markdown 内容，上传图片，设置标签
5. 选择分区 → 提交审核
