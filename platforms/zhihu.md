# 知乎平台规范

## 输出格式
- 主格式：Markdown（知乎原生支持）
- 备用格式：Word 文档 (.docx)

## 内容参数
- 字数：2000-5000 字
- 标题：专业严谨，清晰表达核心观点
- 风格：专业、有数据支撑、逻辑链完整
- 结构：开头抛出问题/观点 → 论证过程 → 总结

## 配图要求
- 比例：16:9
- 数量：1-3 张
- 类型：信息图、数据图表、流程图
- 图片风格：专业、简洁

## SEO / 关键词
- 标题包含核心搜索词
- 正文自然分布关键词
- 适合知乎站内搜索优化

## 排版特性
- 支持代码块（``` 语法）
- 支持表格
- 支持引用（> 语法）
- 支持加粗、斜体
- 长文善用小标题分段

## 文件命名
- `zhihu_{slug}.md`
- `zhihu_{slug}.docx`
- `images/zhihu_{n}.png`

## 手动发布指引
1. 登录知乎
2. 写文章 或 写回答
3. 直接粘贴 Markdown 内容
4. 上传配图（通过拖拽或插入图片功能）
